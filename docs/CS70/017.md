# 017 - 随机变量的函数

在上一讲中，我们考虑了随机变量的简单线性函数（和、差和常数倍）。在本讲中，我们将考虑随机变量更一般的函数。

形式上，令 $X$ 是样本空间 $\Omega$ 上的一个随机变量，其概率分布为 $\mathbb { P } _ { X }$ 。那么，对于 $X$ 值域上的函数 $f ( \cdot )$ ， $f ( X )$ 也是同一样本空间 $\Omega$ 上的一个随机变量。设 $Y = f ( X )$ ，对于 $\omega \in \Omega$ ，我们有 $Y ( \omega ) = f ( X ( \omega ) )$ 。

从样本空间的角度来看，事件 “$Y = y$” 等价于事件 “$X \in f ^ { - 1 } ( y )$”，其中 $f ^ { - 1 } ( y )$ 表示原像 $\{ x \mid f ( x ) = y \}$ 。（当 $f ( \cdot )$ 是单射时会更简单，即 “$X = x$” 与 “$Y = f ( x )$” 是同一个事件。）

以此视角， $Y = f ( X )$ 的分布 $\mathbb { P } _ { Y }$ 可以从 $X$ 的分布推导如下：

$$
\mathbb {P} _ {Y} [ Y = y ] = \sum_ {x: f (x) = y} \mathbb {P} _ {X} [ X = x ]. \tag {1}
$$

由此，我们观察到

$$
\mathbb {E} [ Y ] = \sum_ {y} y \mathbb {P} _ {Y} [ Y = y ] = \sum_ {y} \sum_ {x: f (x) = y} y \mathbb {P} _ {X} [ X = x ] = \sum_ {x} f (x) \mathbb {P} _ {X} [ X = x ].
$$

第一个等号是根据期望的定义，第二个是由 (1) 式得出，最后一个是通过观察到每个 $x$ 值在内层求和中恰好出现一次。因此，我们有以下恒等式：

$$
\mathbb {E} [ f (X) ] = \sum_ {x} f (x) \mathbb {P} _ {X} [ X = x ].
$$

换言之：要计算 $f ( X )$ 的期望，我们采取与 $X$ 的普通期望相同的加权平均方式，但将 $X$ 的值 $x$ 替换为 $f ( x )$ 。（这个恒等式有时被称为**无意识统计学家定律**（Law of the Unconscious Statistician，简称 LOTUS），因为它非常有用，且有时在不假思索的情况下被使用。）

我们将广泛使用的一个例子如下：对于任何随机变量 $X$ ，我们有 $\textstyle \mathbb { E } [ X ^ { 2 } ] = \sum _ { x } x ^ { 2 } \mathbb { P } _ { X } [ X = x ]$ 。注意：请注意 $\mathbb { E } [ X ^ { 2 } ]$ 与 $( \mathbb { E } [ X ] ) ^ { 2 }$ 并不相同。同样，一般情况下， $\mathbb { E } [ f ( X ) ]$ 与 $f ( \mathbb { E } [ X ] )$ 也不相同，除非 $f$ 具有 $f ( X ) = a X + b$ 的形式（其中 $a$ 和 $b$ 是常数）。

# 随机变量：方差和协方差
我们在上一讲中看到，如果我们拿一枚以概率 $p$ 出现正面的有偏硬币并抛掷 $n$ 次，那么正面的期望次数是 $n p$ 。这意味着如果我们多次重复该实验（每次实验抛掷硬币 $n$ 次），那么平均而言我们会得到 $n p$ 个正面。但在任何单词实验中，观察到的正面次数可以是从 0 到 $n$ 之间的任何值。关于我们离期望值有多远，能说些什么呢？也就是说，正面次数距离 $n p$ 的典型偏差是多少？

## 1 随机游走
让我们考虑一个比抛掷公平硬币 $n$ 次更简单但更容易想象的设置。假设我们有一个粒子从位置 0 开始，在一维空间进行随机游走。在每个时间步，粒子以相等的概率向右或向左移动一步（这种随机游走被称为对称的），并且每个时间步的移动独立于所有其他移动。我们认为这些随机移动是根据公平硬币出现正面或反面进行的。粒子在 $n$ 次移动后的期望位置回到 0，但通常我们应该期望粒子距离 0 有多远？

将向右移动记为 $+1$ ，向左移动记为 $-1$ ，我们可以将这里的概率空间描述为字母表 $\{ \pm 1 \}$ 上长度为 $n$ 的所有序列的集合，每个序列具有相等的概率 $\frac { 1 } { 2 ^ { n } }$ 。令随机变量 $S _ { n }$ 表示粒子在 $n$ 次移动后相对于起点 0 的位置。因此，我们可以写成

$$
S _ {n} = X _ {1} + X _ {2} + \dots + X _ {n}, \tag {2}
$$

其中，如果第 $i$ 步向右移，则 $X _ { i } = + 1$ ；如果向左移，则 $X _ { i } = - 1$ 。

$S _ { n }$ 的期望可以很容易地计算如下。由于 $\textstyle \mathbb { E } [ X _ { i } ] = ( \frac { 1 } { 2 } \times 1 ) + ( \frac { 1 } { 2 } \times ( - 1 ) ) = 0$ ，应用期望的线性性质立即得到 $\textstyle \mathbb { E } [ S _ { n } ] = \sum _ { i = 1 } ^ { n } \mathbb { E } [ X _ { i } ] = 0$ 。但这当然没有太多信息量，这是由于离开 0 的正向和负向偏差相互抵消了。

我们真正想问的是： $\vert S _ { n } \vert$ （粒子距离 0 的距离）的期望值是多少？

与其考虑由于绝对值算子而有点难以处理的随机变量 $\vert S _ { n } \vert$ ，我们转而研究随机变量 $S _ { n } ^ { 2 }$ 。请注意，这也具有使所有偏离 0 的值变为正的效果，因此它也应该能够很好地衡量到 0 的距离。然而，因为它是平方距离，我们最后需要取平方根。

我们现在将证明在 $n$ 步后的预期平方距离等于 $n$ 。

**命题 17.1**。对于 (2) 式中定义的随机变量 $S _ { n }$ ，我们有 $\mathbb { E } [ S _ { n } ^ { 2 } ] = n$ 。

**证明**。我们利用 (2) 中的表达式并展开平方：

$$
\mathbb {E} \left[ S _ {n} ^ {2} \right] = \mathbb {E} \left[ \left(X _ {1} + X _ {2} + \dots + X _ {n}\right) ^ {2} \right] = \mathbb {E} \left[ \sum_ {i = 1} ^ {n} X _ {i} ^ {2} + 2 \sum_ {i <   j} X _ {i} X _ {j} \right] = \sum_ {i = 1} ^ {n} \mathbb {E} \left[ X _ {i} ^ {2} \right] + 2 \sum_ {i <   j} \mathbb {E} \left[ X _ {i} X _ {j} \right]. \tag {3}
$$

在最后一个等号中，我们使用了期望的线性性质。接下来，我们需要计算 $i \neq j$ 时的 $\mathbb { E } [ X _ { i } ^ { 2 } ]$ 和 $\mathbb { E } [ X _ { i } X _ { j } ]$ 。由于 $X _ { i }$ 只能取 $\pm 1$ ，显然始终有 $X _ { i } ^ { 2 } = 1$ ，因此 $\mathbb { E } [ X _ { i } ^ { 2 } ] = 1$ 。要计算 $i \neq j$ 时的 $\mathbb { E } [ X _ { i } X _ { j } ]$ ，注意当 $X _ { i } = X _ { j } = + 1$ 或 $X _ { i } = X _ { j } = - 1$ 时 $X _ { i } X _ { j } = + 1$ ，否则 $X _ { i } X _ { j } = - 1$ 。因此，

$$
\begin{array}{l} \mathbb {P} \left[ X _ {i} X _ {j} = 1 \right] = \mathbb {P} \left[ \left(X _ {i} = X _ {j} = + 1\right) \vee \left(X _ {i} = X _ {j} = - 1\right) \right] \\ = \mathbb {P} [ X _ {i} = X _ {j} = + 1 ] + \mathbb {P} [ X _ {i} = X _ {j} = - 1 ] \\ = \mathbb {P} [ X _ {i} = + 1 ] \times \mathbb {P} [ X _ {j} = + 1 ] + \mathbb {P} [ X _ {i} = - 1 ] \times \mathbb {P} [ X _ {j} = - 1 ] \\ = \frac {1}{4} + \frac {1}{4} = \frac {1}{2}, \\ \end{array}
$$

其中第二个等号源于事件 $X _ { i } = X _ { j } = + 1$ 和 $X _ { i } = X _ { j } = - 1$ 是互斥的，而第三个等号源于事件 $X _ { i } = + 1$ 和 $X _ { j } = + 1$ 的独立性，以及事件 $X _ { i } = - 1$ 和 $X _ { j } = - 1$ 的独立性。由于 $X _ { i } X _ { j }$ 唯一可能的其它值为 $-1$ ，我们必定也有 $\mathbb { P } [ X _ { i } X _ { j } = - 1 ] = \frac { 1 } { 2 }$ ，因此 $\mathbb { E } [ X _ { i } X _ { j } ] = 0$ 。[注：稍后我们将看到一种更简单的方法来计算 $\mathbb { E } [ X _ { i } X _ { j } ]$ ，即利用 $X _ { i }$ 和 $X _ { j }$ 独立这一事实。]

最后，将 $i \neq j$ 时的 $\mathbb { E } [ X _ { i } ^ { 2 } ] = 1$ 和 $\mathbb { E } [ X _ { i } X _ { j } ] = 0$ 代入 (3) 式，得到 $\textstyle \mathbb { E } [ S _ { n } ^ { 2 } ] = \sum _ { i = 1 } ^ { n } 1 + 2 \sum _ { i < j } 0 = n$ ，正如所声明的那样。 $\square$

所以，对于对称随机游走示例，我们看到距离 0 的预期平方距离是 $n$ 。对此的一种解释是，我们可能期望在 $n$ 步之后距离 0 大约有 $\sqrt { n }$ 的距离。然而，我们在这里必须小心：我们不能简单地断言 $\mathbb { E } [ \vert S _ { n } \vert ] = \sqrt { \mathbb { E } [ S _ { n } ^ { 2 } ] } = \sqrt { n }$ 。（为什么不能？）我们将在本课程的后面看到如何从 $\mathbb { E } [ S _ { n } ^ { 2 } ]$ 的知识中对 $\vert S _ { n } \vert$ 做出精确推断。然而目前，让我们同意将 $\mathbb { E } [ S _ { n } ^ { 2 } ]$ 视为对随机变量 $S _ { n } $ “分布范围（散布）”的一个直观度量。

对于期望为 $\mathbb { E } [ X ] = \mu$ 的更一般的随机变量 $X$ ，我们真正感兴趣的是 $\mathbb { E } [ ( X - \mu ) ^ { 2 } ]$ ，即距离均值的预期平方距离。在我们的对称随机游走示例中，由于 $\mathbb { E } [ S _ { n } ] = \mu = 0$ ，所以 $\mathbb { E } [ ( S _ { n } - \mu ) ^ { 2 } ]$ 就简化为了 $\mathbb { E } [ S _ { n } ^ { 2 } ]$ 。

**定义 17.1**（方差）。对于一个期望为 $\mathbb { E } [ X ] = \mu$ 的随机变量 $X$ ， $X$ 的**方差**（Variance）定义为

$$
\operatorname {V a r} (X) = \mathbb {E} \left[ (X - \mu) ^ {2} \right].
$$

其平方根 $\sigma ( X ) : = \sqrt { \operatorname { V a r } ( X ) }$ 被称为 $X$ 的**标准差**（Standard Deviation）。

对方差取平方根的意义在于使标准差与随机变量本身处于 “同一量级（Scale）”。由于方差和标准差仅差一个平方，我们选择研究哪一个其实并不重要，因为我们总能从一个计算出另一个。我们通常会使用方差。对于上述随机游走示例，命题 17.1 暗示 $\operatorname { V a r } ( S _ { n } ) = n$ ，且标准差为 $\sigma ( S _ { n } ) = \sqrt { n }$ 。

以下观察提供了一种略有不同的方差计算方法，有时证明这种方法更简单。

**定理 17.1**。对于一个期望为 $\mathbb { E } [ X ] = \mu$ 的随机变量 $X$ ，我们有 $\operatorname { V a r } ( X ) = \mathbb { E } [ X ^ { 2 } ] - \mu ^ { 2 }$ 。

**证明**。根据方差的定义，我们有

$$
\operatorname {V a r} (X) = \mathbb {E} \left[ (X - \mu) ^ {2} \right] = \mathbb {E} \left[ X ^ {2} - 2 \mu X + \mu^ {2} \right] = \mathbb {E} \left[ X ^ {2} \right] - 2 \mu \mathbb {E} [ X ] + \mu^ {2} = \mathbb {E} \left[ X ^ {2} \right] - \mu^ {2}.
$$

在第三个等号中，我们使用了期望的线性性质；注意，由于 $\mu = \mathbb { E } [ X ]$ 是一个常数， $\mathbb { E } [ \mu X ] = \mu \mathbb { E } [ X ] = \mu ^ { 2 }$ 且 $\mathbb { E } [ \mu ^ { 2 } ] = \mu ^ { 2 }$ 。 $\square$

另一个派上用场的性质如下：对于任何随机变量 $X$ 和常数 $c$ ，我们有

$$
\operatorname {V a r} (c X) = c ^ {2} \operatorname {V a r} (X). \tag {4}
$$

验证这一点非常直接，留作练习。

## 2 方差计算
让我们看一些方差计算的例子。

1. 公平筛子。令 $X$ 为掷一次公平筛子的点数。从上一讲中回想 $\textstyle \mathbb { E } [ X ] = \frac { 7 } { 2 }$ 。所以我们只需要计算 $\mathbb { E } [ X ^ { 2 } ]$ ，这是一个常规计算：

$$
\mathbb {E} \left[ X ^ {2} \right] = \frac {1}{6} \left(1 ^ {2} + 2 ^ {2} + 3 ^ {2} + 4 ^ {2} + 5 ^ {2} + 6 ^ {2}\right) = \frac {9 1}{6}.
$$

因此，根据定理 17.1，

$$
\operatorname {V a r} (X) = \mathbb {E} [ X ^ {2} ] - (\mathbb {E} [ X ]) ^ {2} = \frac {9 1}{6} - \frac {4 9}{4} = \frac {3 5}{1 2}.
$$

2. 均匀分布。更一般地，假设 $X$ 是集合 $\{ 1 , \ldots , n \}$ 上的**均匀随机变量**（Uniform Random Variable），记作 $X \sim \operatorname { U n i f o r m } \{ 1 , \ldots , n \}$ ，即 $X$ 以相等的概率 $\frac { 1 } { n }$ 取值 $1 , \ldots , n$ 。 $X$ 的均值、方差和标准差由下式给出：

$$
\mathbb {E} [ X ] = \frac {n + 1}{2}, \quad \operatorname {V a r} (X) = \frac {n ^ {2} - 1}{1 2}, \quad \sigma (X) = \sqrt {\frac {n ^ {2} - 1}{1 2}}. \tag {5}
$$

你应该将其作为练习进行验证。[回想 $\textstyle \sum _ { i = 1 } ^ { n } i = \frac { n ( n + 1 ) } { 2 }$ 且 $\textstyle \sum _ { i = 1 } ^ { n } i ^ { 2 } = \frac { n ( n + 1 ) ( 2 n + 1 ) } { 6 }$ 。]

3. 置换的固定点。令 $X _ { n }$ 为 $n$ 个物品随机置换中固定点的数量（例如，在作业置换例子中， $X _ { n }$ 是规模为 $n$ 的班级中在打乱后收到自己作业的学生人数）。我们在上一讲中看到，无论 $n$ 是多少， $\mathbb { E } [ X _ { n } ] = 1$ 。为了计算 $\mathbb { E } [ X _ { n } ^ { 2 } ]$ ，设 $X _ { n } = I _ { 1 } + I _ { 2 } + \cdots + I _ { n }$ ，其中如果 $i$ 是固定点则 $I _ { i } = 1$ ，否则 $I _ { i } = 0$ 。那么按照惯例，我们有

$$
\mathbb {E} \left[ X _ {n} ^ {2} \right] = \sum_ {i = 1} ^ {n} \mathbb {E} \left[ I _ {i} ^ {2} \right] + 2 \sum_ {i <   j} \mathbb {E} \left[ I _ {i} I _ {j} \right]. \tag {6}
$$

由于 $I _ { i }$ 是指示随机变量，我们有 $\textstyle \mathbb { E } [ I _ { i } ^ { 2 } ] = \mathbb { P } [ I _ { i } = 1 ] = \frac { 1 } { n }$ 。对于 $i < j$ ，由于 $I _ { i }$ 和 $I _ { j }$ 都是指示变量，我们可以计算 $\mathbb { E } [ I _ { i } I _ { j } ]$ 如下：

$$
\mathbb {E} \left[ I _ {i} I _ {j} \right] = \mathbb {P} \left[ I _ {i} I _ {j} = 1 \right] = \mathbb {P} \left[ I _ {i} = 1 \wedge I _ {j} = 1 \right] = \mathbb {P} [ i \text { 和 } j \text { 都是固定点} ] = \frac {1}{n (n - 1)}.
$$

确保你理解这一步！将其代入 (6) 式我们得到

$$
\mathbb {E} \left[ X _ {n} ^ {2} \right] = \sum_ {i = 1} ^ {n} \frac {1}{n} + 2 \sum_ {i <   j} \frac {1}{n (n - 1)} = \left(n \times \frac {1}{n}\right) + \left[ 2 \binom {n} {2} \times \frac {1}{n (n - 1)} \right] = 1 + 1 = 2.
$$

因此， $\operatorname { V a r } ( X _ { n } ) = \mathbb { E } [ X _ { n } ^ { 2 } ] - ( \mathbb { E } [ X _ { n } ] ) ^ { 2 } = 2 - 1 = 1$ 。也就是说，方差和均值都等于 1。与均值一样，方差也与 $n$ 无关。至少从直觉上讲，这意味着即使物品数量 $n$ 非常大，也不太可能出现超过少量固定点的情况。

## 3 独立随机变量之和
关于方差最重要且最实用的事实之一是：如果一个随机变量 $X$ 是若干独立随机变量之和 $X = X _ { 1 } + \cdots + X _ { n }$ ，那么它的方差就是这些随机变量各自方差之和。特别地，如果各随机变量 $X _ { i }$ 是**独立同分布**（Identically Distributed，即它们具有相同的分布）的，那么 $\operatorname { V a r } ( X ) = \sum _ { i = 1 } ^ { n } \operatorname { V a r } ( X _ { i } ) = n \cdot \operatorname { V a r } ( X _ { 1 } )$ 。这意味着标准差为 $\sigma ( X ) = \sqrt { n } \cdot \sigma ( X _ { 1 } )$ 。

相比之下，期望值为 $\mathbb { E } [ X ] = n \cdot \mathbb { E } [ X _ { 1 } ]$ 。直观上，这意味着虽然 $X$ 的虽然 $\operatorname { c o v } ( X , Y )$ 的符号（正或负）能反映出 $X$ 和 $Y$ 是如何关联的，但其大小却难以解释。一个更容易解释的统计量是**相关系数**（Correlation）：

**定义 17.3**（相关系数）。假设 $X$ 和 $Y$ 是随机变量，且 $\sigma ( X ) > 0$ 以及 $\sigma ( Y ) > 0$ 。那么， $X$ 和 $Y$ 的**相关系数**（Correlation）定义为

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)}.
$$

相关系数比协方差更有用，因为前者总是介于 $-1$ 和 $+1$ 之间，如下面定理所示：

**定理 17.4**。对于任何 $\sigma ( X ) > 0$ 且 $\sigma ( Y ) > 0$ 的随机变量对 $X$ 和 $Y$ ：

$$
- 1 \leq \operatorname {C o r r} (X, Y) \leq + 1.
$$

**证明**。令 $\mathbb { E } [ X ] = \mu _ { X }$ 且 $\mathbb { E } [ Y ] = \mu _ { Y }$ ，并定义 $\widetilde { X } = ( X - \mu _ { X } ) / \sigma ( X )$ 以及 $\widetilde { Y } = ( Y - \mu _ { Y } ) / \sigma ( Y )$ 。那么 $\mathbb { E } [ \widetilde { X } ^ { 2 } ] = \mathbb { E } [ \widetilde { Y } ^ { 2 } ] = 1$ ，所以

$$
0 \leq \mathbb {E} [ (\widetilde {X} - \widetilde {Y}) ^ {2} ] = \mathbb {E} [ \widetilde {X} ^ {2} ] + \mathbb {E} [ \widetilde {Y} ^ {2} ] - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ] = 2 - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ]
$$

$$
0 \leq \mathbb {E} \left[ \left(\widetilde {X} + \widetilde {Y}\right) ^ {2} \right] = \mathbb {E} \left[ \widetilde {X} ^ {2} \right] + \mathbb {E} \left[ \widetilde {Y} ^ {2} \right] + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right] = 2 + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right],
$$

这暗示了 $- 1 \le \mathbb { E } [ \widetilde { X } \widetilde { Y } ] \le + 1$ 。最后，注意

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)} = \frac {\mathbb {E} \left[ \left(X - \mu_ {X}\right) \left(Y - \mu_ {Y}\right) \right]}{\sigma (X) \sigma (Y)} = \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right].
$$

因此，我们可以推断出 $- 1 \leq \operatorname { C o r r } ( X , Y ) \leq + 1$ 。

请注意，上述证明显示 $\operatorname { C o r r } ( X , Y ) = + 1$ 当且仅当 $\mathbb { E } [ ( \widetilde { X } - \widetilde { Y } ) ^ { 2 } ] = 0$ ，这暗示了 $\widetilde { X } = \widetilde { Y }$ 以概率 1 成立。类似地， $\operatorname { C o r r } ( X , Y ) = - 1$ 当且仅当 $\mathbb { E } [ ( \widetilde { X } + \widetilde { Y } ) ^ { 2 } ] = 0$ ，这暗示了 $\widetilde { X } = - \widetilde { Y }$ 以概率 1 成立。对于原始随机变量 $X, Y$ 而言，这意味着：如果 $\operatorname { C o r r } ( X , Y ) = \pm 1$ ，那么存在常数 $a$ 和 $b$ 使得以概率 1 成立

$$
Y = a X + b,
$$

其中如果 $\operatorname { C o r r } ( X , Y ) = + 1$ 则 $a > 0$ ，如果 $\operatorname { C o r r } ( X , Y ) = - 1$ 则 $a < 0$ 。（值 $a, b$ 特别地取决于 $\mu _ { X } , \mu _ { Y } , \sigma ( X ) , \sigma ( Y )$ ；具体而言 $a = \pm \frac { \sigma ( Y ) } { \sigma ( X ) }$ ，符号取决于 $\operatorname { C o r r } ( X , Y ) = \pm 1$ 。）因此 $X$ 和 $Y$ 仅相差一个比例因子和一次位移。
mathbb { E } [ I _ { i } ] = n p$ 。我们可以计算 $\operatorname { V a r } ( I _ { i } ) = \mathbb { E } [ I _ { i } ^ { 2 } ] - \mathbb { E } [ I _ { i } ] ^ { 2 } = p - p ^ { 2 } = p ( 1 - p )$ 。由于 $I _ { i }$ 是独立的，根据定理 17.3，我们得到 $\operatorname { V a r } ( X _ { n } ) = \sum _ { i = 1 } ^ { n } \operatorname { V a r } ( I _ { i } ) = n p ( 1 - p )$ 。

例如，对于公平硬币 $( p = \frac { 1 } { 2 } )$ ， $n$ 次抛掷中正面的期望次数是 $\frac { n } { 2 }$ ，标准差是 $\sqrt { \frac { n } { 4 } } = \frac { \sqrt { n } } { 2 }$ 。请注意，由于正面的最大数量是 $n$ ，对于较大的 $n$ ，标准差远小于这个最大值。这与 (5) 式中均匀分布随机变量的前一个例子形成对比，在那个例子中，标准差 $\sigma ( X ) = \sqrt { \frac { n ^ { 2 } - 1 } { 1 2 } } \approx \frac { n } { \sqrt { 1 2 } }$ （对于大 $n$ ）与最大值 $n$ 属于同一数量级。在这个意义上，二项分布随机变量的散布程度远小于均匀分布随机变量。

# 4 协方差和相关系数
定理 17.3 证明中的表达式 $\mathbb { E } [ X Y ] - \mathbb { E } [ X ] \mathbb { E } [ Y ]$ 是对 $X, Y$ 之间关联性的一种度量，被称为**协方差**（Covariance）：

**定义 17.2**（协方差）。随机变量 $X$ 和 $Y$ 的**协方差**（Covariance）记作 $\operatorname { c o v } ( X , Y )$ ，定义为

$$
\operatorname {c o v} (X, Y) = \mathbb {E} \left[ \left(X - \mu_ {X}\right) \left(Y - \mu_ {Y}\right) \right] = \mathbb {E} [ X Y ] - \mathbb {E} [ X ] \mathbb {E} [ Y ],
$$

其中 $\mu _ { X } = \mathbb { E } [ X ]$ 且 $\mu _ { Y } = \mathbb { E } [ Y ]$ 。

**练习**：检查上述两个关于 $\operatorname { c o v } ( X , Y )$ 的表达式确实相等。

**备注**。我们指出关于协方差的一些重要事实。

1. 如果 $X, Y$ 独立，那么 $\operatorname { c o v } ( X , Y ) = 0$ 。然而，反之则不一定成立。
2. $\operatorname { c o v } ( X , X ) = \operatorname { V a r } ( X )$ 。
3. 协方差是双线性的；也就是说，对于任何随机变量集合 $\{ X _ { 1 } , \ldots , X _ { n } \} , \{ Y _ { 1 } , \ldots , Y _ { m } \}$ 和固定常数 $\{ a _ { 1 } , \ldots , a _ { n } \} , \{ b _ { 1 } , \ldots , b _ { m } \}$ ，

$$
\operatorname {c o v} \left(\sum_ {i = 1} ^ {n} a _ {i} X _ {i}, \sum_ {j = 1} ^ {m} b _ {j} Y _ {j}\right) = \sum_ {i = 1} ^ {n} \sum_ {j = 1} ^ {m} a _ {i} b _ {j} \operatorname {c o v} \left(X _ {i}, Y _ {j}\right).
$$

对于一般的随机变量 $X$ 和 $Y$ ，

$$
\operatorname {V a r} (X + Y) = \operatorname {V a r} (X) + \operatorname {V a r} (Y) + 2 \operatorname {c o v} (X, Y).
$$

While the sign of $\operatorname { c o v } ( X , Y )$ (positive or negative) is informative of how $X$ and $Y$ are associated, its magnitude is difficult to interpret. A statistic that is easier to interpret is correlation:

Definition 17.3 (Correlation). Suppose $X$ and Y are random variables with $\sigma ( \boldsymbol X ) > 0$ and $\sigma ( Y ) > 0$ . Then, the correlation of X and Y is defined as

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)}.
$$

Correlation is more useful than covariance because the former always ranges between $^ { - 1 }$ and $+ 1$ , as the following theorem shows:

Theorem 17.4. For any pair of random variables $X$ and $Y$ with $\sigma ( \boldsymbol X ) > 0$ and $\sigma ( Y ) > 0 ;$

$$
- 1 \leq \operatorname {C o r r} (X, Y) \leq + 1.
$$

Proof. Let $\mathbb { E } [ X ] = \mu _ { X }$ and $\mathbb { E } [ Y ] = \mu _ { Y }$ , and define $\widetilde { X } = ( X - \mu _ { X } ) / \sigma ( X )$ and $\widetilde { Y } = ( Y - \mu _ { Y } ) / \sigma ( Y )$ . Then, $\mathbb { E } [ \widetilde { X } ^ { 2 } ] = \mathbb { E } [ \widetilde { Y } ^ { 2 } ] = 1$ , so

$$
0 \leq \mathbb {E} [ (\widetilde {X} - \widetilde {Y}) ^ {2} ] = \mathbb {E} [ \widetilde {X} ^ {2} ] + \mathbb {E} [ \widetilde {Y} ^ {2} ] - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ] = 2 - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ]
$$

$$
0 \leq \mathbb {E} \left[ \left(\widetilde {X} + \widetilde {Y}\right) ^ {2} \right] = \mathbb {E} \left[ \widetilde {X} ^ {2} \right] + \mathbb {E} \left[ \widetilde {Y} ^ {2} \right] + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right] = 2 + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right],
$$

which implies $- 1 \le \mathbb { E } [ \widetilde { X } \widetilde { Y } ] \le + 1 .$ . Finally, note that

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)} = \frac {\mathbb {E} \left[ \left(X - \mu_ {X}\right) \left(Y - \mu_ {Y}\right) \right]}{\sigma (X) \sigma (Y)} = \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right].
$$

Therefore, we can deduce that $- 1 \leq \mathbf { C o r r } ( X , Y ) \leq + 1$ .

Note that the above proof shows that $\operatorname { C o r r } ( X , Y ) = + 1$ if and only if $\mathbb { E } [ ( \widetilde { X } - \widetilde { Y } ) ^ { 2 } ] = 0$ , which implies $\widetilde { X } = \widetilde { Y }$ with probability 1. Similarly, $\operatorname { C o r r } ( X , Y ) = - 1$ if and only if $\mathbb { E } [ ( \widetilde { X } + \widetilde { Y } ) ^ { 2 } ] = 0$ , which implies $\widetilde { X } = - \widetilde { Y }$ with probability 1. In terms of the original random variables $X , Y$ , this means the following: if $\operatorname { C o r r } ( X , Y ) = \pm 1$ , then there exist constants $a$ and $^ b$ such that, with probability 1,

$$
虽然 $\operatorname { c o v } ( X , Y )$ 的符号（正或负）能反映出 $X$ 和 $Y$ 是如何关联的，但其大小却难以解释。一个更容易解释的统计量是**相关系数**（Correlation）：

**定义 17.3**（相关系数）。假设 $X$ 和 $Y$ 是随机变量，且 $\sigma ( X ) > 0$ 以及 $\sigma ( Y ) > 0$ 。那么， $X$ 和 $Y$ 的**相关系数**（Correlation）定义为

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)}.
$$

相关系数比协方差更有用，因为前者总是介于 $-1$ 和 $+1$ 之间，如下面定理所示：

**定理 17.4**。对于任何 $\sigma ( X ) > 0$ 且 $\sigma ( Y ) > 0$ 的随机变量对 $X$ 和 $Y$ ：

$$
- 1 \leq \operatorname {C o r r} (X, Y) \leq + 1.
$$

**证明**。令 $\mathbb { E } [ X ] = \mu _ { X }$ 且 $\mathbb { E } [ Y ] = \mu _ { Y }$ ，并定义 $\widetilde { X } = ( X - \mu _ { X } ) / \sigma ( X )$ 以及 $\widetilde { Y } = ( Y - \mu _ { Y } ) / \sigma ( Y )$ 。那么 $\mathbb { E } [ \widetilde { X } ^ { 2 } ] = \mathbb { E } [ \widetilde { Y } ^ { 2 } ] = 1$ ，所以

$$
0 \leq \mathbb {E} [ (\widetilde {X} - \widetilde {Y}) ^ {2} ] = \mathbb {E} [ \widetilde {X} ^ {2} ] + \mathbb {E} [ \widetilde {Y} ^ {2} ] - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ] = 2 - 2 \mathbb {E} [ \widetilde {X} \widetilde {Y} ]
$$

$$
0 \leq \mathbb {E} \left[ \left(\widetilde {X} + \widetilde {Y}\right) ^ {2} \right] = \mathbb {E} \left[ \widetilde {X} ^ {2} \right] + \mathbb {E} \left[ \widetilde {Y} ^ {2} \right] + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right] = 2 + 2 \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right],
$$

这暗示了 $- 1 \le \mathbb { E } [ \widetilde { X } \widetilde { Y } ] \le + 1$ 。最后，注意

$$
\operatorname {C o r r} (X, Y) = \frac {\operatorname {c o v} (X , Y)}{\sigma (X) \sigma (Y)} = \frac {\mathbb {E} \left[ \left(X - \mu_ {X}\right) \left(Y - \mu_ {Y}\right) \right]}{\sigma (X) \sigma (Y)} = \mathbb {E} \left[ \widetilde {X} \widetilde {Y} \right].
$$

因此，我们可以推断出 $- 1 \leq \operatorname { C o r r } ( X , Y ) \leq + 1$ 。

请注意，上述证明显示 $\operatorname { C o r r } ( X , Y ) = + 1$ 当且仅当 $\mathbb { E } [ ( \widetilde { X } - \widetilde { Y } ) ^ { 2 } ] = 0$ ，这暗示了 $\widetilde { X } = \widetilde { Y }$ 以概率 1 成立。类似地， $\operatorname { C o r r } ( X , Y ) = - 1$ 当且仅当 $\mathbb { E } [ ( \widetilde { X } + \widetilde { Y } ) ^ { 2 } ] = 0$ ，这暗示了 $\widetilde { X } = - \widetilde { Y }$ 以概率 1 成立。对于原始随机变量 $X, Y$ 而言，这意味着：如果 $\operatorname { C o r r } ( X , Y ) = \pm 1$ ，那么存在常数 $a$ 和 $b$ 使得以概率 1 成立

$$
Y = a X + b,
$$

其中如果 $\operatorname { C o r r } ( X , Y ) = + 1$ 则 $a > 0$ ，如果 $\operatorname { C o r r } ( X , Y ) = - 1$ 则 $a < 0$ 。（值 $a, b$ 特别地取决于 $\mu _ { X } , \mu _ { Y } , \sigma ( X ) , \sigma ( Y )$ ；具体而言 $a = \pm \frac { \sigma ( Y ) } { \sigma ( X ) }$ ，符号取决于 $\operatorname { C o r r } ( X , Y ) = \pm 1$ 。）因此 $X$ 和 $Y$ 仅相差一个比例因子和一次位移。
