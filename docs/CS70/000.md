# 000 - 集合与数学符号回顾

**集合**（Set）是对象的良定义集合。这些对象被称为集合的 **元素**（Element）或 **成员**（Member），它们可以是任何东西，包括数字、字母、人、城市，甚至其他集合。按照惯例，集合通常用大写字母表示，可以通过列出其元素并将列表用花括号括起来来描述或定义。例如，我们可以将集合 $A$ 描述为成员是前五个质数的集合，或者我们可以显式地写成： $A = \{ 2, 3, 5, 7, 11 \}$ 。如果 $x$ 是 $A$ 的一个元素，那么我们记作 $x \in A$ 。类似地，如果 $y$ 不是 $A$ 的一个元素，那么我们记作 $y \notin A$ 。如果两个集合 $A$ 和 $B$ 具有相同的元素，则称它们相等，记作 $A = B$ 。元素的顺序和重复并不重要，因此 {red, white, blue} $=$ {blue, white, red} $=$ {red, white, white, blue}。有时，可以使用不同的符号定义更复杂的集合。例如，所有有理数的集合，记作 $\mathbb{Q}$ ，可以写成： $\textstyle \{ \frac{a}{b} \mid a, b$ 是整数, $b \neq 0 \}$ 。在英语中，这读作“所有分子为整数且分母为非零整数的分数的集合”。

## 1 基数
我们还可以讨论集合的大小，或其 **基数**（Cardinality）。如果 $A = \{ 1, 2, 3, 4 \}$ ，那么 $A$ 的基数记作 $| A |$ ，为 4。集合的基数可能为 0。存在唯一的这样一个集合，称为 **空集**（Empty Set），用符号 $\emptyset$ 表示。集合也可以有无限数量的元素，例如所有整数、质数或奇数的集合。

## 2 子集与真子集
如果集合 $A$ 的每个元素也都在集合 $B$ 中，那么我们说 $A$ 是 $B$ 的 **子集**（Subset），记作 $A \subseteq B$ 。等价地，我们可以写成 $B \supseteq A$ ，或 $B$ 是 $A$ 的 **超集**（Superset）。 **真子集**（Proper Subset） 是严格包含在 $B$ 中的集合 $A$ ，记作 $A \subset B$ ，这意味着 $A$ 至少排除了 $B$ 中的一个元素。例如，考虑集合 $B = \{ 1, 2, 3, 4, 5 \}$ 。那么 $\{ 1, 2, 3 \}$ 既是 $B$ 的子集也是真子集，而 $\{ 1, 2, 3, 4, 5 \}$ 是 $B$ 的子集但不是真子集。以下是关于子集的一些基本性质：

- 空集，记作 $\{ \}$ 或 $\emptyset$ ，是任何非空集合 $A$ 的真子集： $\emptyset \subset A$
- 空集是每个集合 $B$ 的子集： $\emptyset \subseteq B$ 。
- 每个集合 $A$ 都是它自身的子集： $A \subseteq A$ 。

## 3 交集与并集
集合 $A$ 与集合 $B$ 的 **交集**（Intersection），记作 $A \cap B$ ，是包含所有既在 $A$ 中又在 $B$ 中的元素的集合。如果 $A \cap B = \emptyset$ ，则称两个集合是 **不相交的**（Disjoint）。集合 $A$ 与集合 $B$ 的 **并集**（Union），记作 $A \cup B$ ，是所有在 $A$ 中或在 $B$ 中或两者都在其中的元素的集合。例如，如果 $A$ 是所有正偶数的集合，而 $B$ 是所有正奇数的集合，那么 $A \cap B = \emptyset$ ，且 $A \cup B = \mathbb{Z}^{+}$ ，即所有正整数的集合。以下是交集和并集的一些性质：

- $A \cup B = B \cup A$
- $A \cup \emptyset = A$

## 5 一些重要的集合
在数学中，一些集合被非常频繁地引用，以至于它们用特殊的符号表示。这些包括：

- $\mathbb{N}$ 表示所有 **自然数**（Natural Numbers） 的集合： $\{ 0, 1, 2, 3, \ldots \}$ 。
- $\mathbb{Z}$ 表示所有 **整数**（Integers） 的集合： $\{ \dots, -2, -1, 0, 1, 2, \dots \}$ 。
- $\mathbb{Q}$ 表示所有 **有理数**（Rational Numbers） 的集合： $\{ \frac{a}{b} \mid a, b \in \mathbb{Z}, b \neq 0 \}$ 。
- $\mathbb{R}$ 表示所有 **实数**（Real Numbers） 的集合。
- $\mathbb{C}$ 表示所有 **复数**（Complex Numbers） 的集合。

## 6 笛卡尔积与幂集
两个集合 $A$ 和 $B$ 的 **笛卡尔积**（Cartesian Product，也称为 **叉积** （Cross Product）），记作 $A \times B$ ，是所有第一个分量是 $A$ 的元素且第二个分量是 $B$ 的元素的有序对的集合。用集合符号表示， $A \times B = \{ ( a, b ) \mid a \in A, b \in B \}$ 。例如，如果 $A = \{ 1, 2, 3 \}$ 且 $B = \{ u, v \}$ ，那么 $A \times B = \{ ( 1, u ), ( 1, v ), ( 2, u ), ( 2, v ), ( 3, u ), ( 3, v ) \}$ 。而 $\mathbb{N} \times \mathbb{N} = \{ ( 0, 0 ), ( 1, 0 ), ( 0, 1 ), ( 1, 1 ), ( 2, 0 ), \ldots \}$ 是所有自然数对的集合。给定一个集合 $S$ ， $S$ 的 **幂集**（Power Set），记作 $\mathcal{P}(S)$ ，是 $S$ 的所有子集的集合： $\{ T \mid T \subseteq S \}$ 。例如，如果 $S = \{ 1, 2, 3 \}$ ，那么 $S$ 的幂集是： $\mathcal{P}(S) = \{ \emptyset, \{ 1 \}, \{ 2 \}, \{ 3 \}, \{ 1, 2 \}, \{ 1, 3 \}, \{ 2, 3 \}, \{ 1, 2, 3 \} \}$ 。注意，如果 $| S | = k$ ，那么 $| \mathcal{P}(S) | = 2^{k}$ 。[为什么？]

## 7 求和与乘积
有一种紧凑的符号用于书写大量项的和或积。例如，为了书写 $1 + 2 + \cdots + n$ 而不必说“点点点”，我们写成 $\sum_{i=1}^{n} i$ 。更一般地，我们可以将和 $f(m) + f(m+1) + \cdots + f(n)$ 写成 $\sum_{i=m}^{n} f(i)$ 。因此，例如， $\sum_{i=5}^{n} i^{2} = 5^{2} + 6^{2} + \dots + n^{2}$ 。

类似地，为了书写乘积 $f(m)f(m+1) \cdots f(n)$ ，我们使用符号 $\prod_{i=m}^{n} f(i)$ 。例如， $\prod_{i=1}^{n} i = 1 \cdot 2 \cdot \cdots \cdot n$ 是前 $n$ 个正整数的乘积。

## 8 全称量词与存在量词
考虑以下陈述：对于所有自然数 $n$ ， $n^{2} + n + 41$ 是质数。这里， $n$ 被量化为自然数集 $\mathbb{N}$ 的任何元素。在符号中，我们写成 $(\forall n \in \mathbb{N}) (n^{2} + n + 41$ 是质数) 。这里我们使用了 **全称量词** (Universal Quantifier) $\forall$ (“对于所有”)。这个陈述是真的吗？如果你尝试代入较小的 $n$ 值，你会发现 $n^{2} + n + 41$ 对于这些值确实是质数。但如果你更努力地思考，你可以找到更大的 $n$ 值，使得它不是质数。你能找到一个吗？因此陈述 $(\forall n \in \mathbb{N}) (n^{2} + n + 41$ 是质数) 是错误的。

**存在量词**（Existential Quantifier） $\exists$ （“存在”）用于以下陈述： $(\exists x \in \mathbb{Z}) (x < 2$ 且 $x^{2} = 4)$ 。该陈述说存在一个小于 2 且其平方等于 4 的整数 $x$ 。这是一个真实的陈述（取 $x = -2$ ）。

我们还可以使用两种量词编写陈述：

1. $(\forall x \in \mathbb{Z})(\exists y \in \mathbb{Z})(y > x)$
2. $(\exists y \in \mathbb{Z})(\forall x \in \mathbb{Z})(y > x)$

第一个陈述说，给定一个整数，我们可以找到一个更大的整数。第二个陈述说的是非常不同的事情：存在一个最大的整数！第一个陈述是真的，第二个陈述不是。
