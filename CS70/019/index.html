    019 - 集中不等式与大数定律

    假设我们有一枚有偏的硬币，但我们并不知道它的偏差是多少。为了估计这个偏差，我们将硬币投掷 \(n\) 次，并记录观察到的正面次数。那么我们对偏差的估计由 \(\hat{p} = \frac{1}{n} S_n\) 给出，其中 \(S_n\) 是 \(n\) 次投掷中正面的次数。这是一个好的估计吗？设 \(p\) 表示硬币的真实偏差，这对我们来说是未知的。由于 \(\mathbb{E}[S_n] = np\) ，我们可以看到估计量 \(\hat{p}\) 始终具有正确的期望值：\(\mathbb{E}[\hat{p}] = \frac{1}{n} \mathbb{E}[S_n] = p\) 。这里的 \(n\) 起什么作用？为什么我们要取多个样本的平均值，而不是只取一个？正如我们将看到的，随着 \(n\) 变得更大，估计值 \(\hat{p}\) 会越来越接近目标值 \(p\) 。这是 大数定律 （Law of Large Numbers）的一种体现，它符合我们自己的经验，我们将在本讲义末尾正式证明它。

    为了保证我们的估计值 \(\hat{p}\) 与真实偏差 \(p\) 的误差在 \(\varepsilon\) 之内（即 \(| \hat{p} - p | \leq \varepsilon\)），\(n\) 应该有多大？答案是我们永远无法以绝对的确定性保证 \(| \hat{p} - p | \leq \varepsilon\) 。这是因为 \(S_n\) 是一个随机变量，可以取 0 到 \(n\) 之间的任何整数值，因此 \(\hat{p} = \frac{1}{n} S_n\) 也是一个随机变量，可以取 0 到 1 之间的任何值。因此，无论真实偏差 \(p \in (0, 1)\) 的值是多少，在我们的 \(n\) 次硬币投掷实验中，观察到 \(n\) 个正面（这以概率 \(p^n\) 发生）是有可能的，在这种情况下 \(S_n = n\) 且 \(\hat{p} = 1\) 。类似地，也有可能所有 \(n\) 次硬币投掷都是反面（这以概率 \((1 - p)^n\) 发生），在这种情况下 \(S_n = 0\) 且 \(\hat{p} = 0\) 。

    因此，与其要求以绝对的确定性使 \(| \hat{p} - p | \leq \varepsilon\) ，不如放宽要求，只要求以 \(1 - \delta\) 的置信度使 \(| \hat{p} - p | \leq \varepsilon\) ，即 \(\mathbb{P}[| \hat{p} - p | \leq \varepsilon] \geq 1 - \delta\) 。这意味着我们有很小的概率 \(\delta\) 会产生超过 \(\varepsilon\) 的误差，但以高概率（至少 \(1 - \delta\)）我们的估计值非常接近 \(p\) 。现在我们可以陈述我们的结果：为了保证 \(\mathbb{P}[| \hat{p} - p | \leq \varepsilon] \geq 1 - \delta\) ，投掷硬币 \(n\) 次就足够了，其中

    \[ n \geq \frac{1}{4 \varepsilon^2 \delta}. \]

    为了证明这样一个结果，我们使用一个叫做 切比雪夫不等式 （Chebyshev’s Inequality）的数学工具，它提供了一个关于随机变量与其期望值之间距离的定量概率界限。

    1 马尔可夫不等式

    在讨论切比雪夫不等式之前，我们首先证明以下更简单的界限，它仅适用于非负随机变量（即仅取值 \(\geq 0\) 的随机变量）。

    定理 19.1（马尔可夫不等式）。对于一个均值有限的非负随机变量 \(X\) （即对于所有 \(\omega \in \Omega\)，都有 \(X(\omega) \geq 0\)），有

    \[ \mathbb{P}[X \geq c] \leq \frac{\mathbb{E}[X]}{c}, \]

    对于任何正数常数 \(c\) 均成立。

    证明。令 \(\mathcal{A}\) 表示 \(X\) 的取值范围，并考虑任何常数 \(c \in \mathcal{A}\) 。那么，

    \[ \begin{array}{l} \mathbb{E}[X] = \sum_{a \in \mathcal{A}} a \times \mathbb{P}[X = a] \\ \geq \sum_{a \geq c} a \times \mathbb{P}[X = a] \\ \geq \sum_{a \geq c} c \times \mathbb{P}[X = a] \\ = c \sum_{a \geq c} \mathbb{P}[X = a] \\ = c \mathbb{P}[X \geq c], \\ \end{array} \]

    其中第一行仅仅是期望的定义，而第二行遵循 \(X\) 是一个非负随机变量这一事实（即对于所有 \(a \in \mathcal{A}\)，\(a \geq 0\)）。整理最后一个不等式即可得到所需结果。 \(\square\)

    （注：在马尔可夫不等式中设定 \(c = 2 \mathbb{E}[X]\)，该陈述是：最多有一半的人可以达到平均水平的两倍以上。）

    可以使用 指示函数 （Indicator Function） \(I\{\cdot\}\) 提供一个更巧妙的证明，对于任何事件 \(\mathcal{E}\)，其定义为

    \[ I\{\mathcal{E}\} = \left\{ \begin{array}{ll} 1, & \text{如果 } \mathcal{E} \text{ 为真,} \\ 0, & \text{如果 } \mathcal{E} \text{ 为假.} \end{array} \right. \]

    定理 19.1 的另一种证明。由于 \(X\) 是一个非负随机变量且 \(c > 0\)，对于所有 \(\omega \in \Omega\)，我们有

    \[ X(\omega) \geq c I\{X(\omega) \geq c\}, \tag{1} \]

    因为如果 \(X(\omega) < c\)，右侧为 0；如果 \(X(\omega) \geq c\)，右侧为 \(c\) 。两边乘以 \(\mathbb{P}[\omega]\) 并对 \(\omega \in \Omega\) 求和得到

    \[ \mathbb{E}[X] \geq c \mathbb{E}[I\{X \geq c\}] = c \mathbb{P}[X \geq c], \]

    其中第一个不等式遵循 (1)，最后一个等式遵循 \(I\{X \geq c\}\) 是一个指示随机变量这一事实。

    如果我们有一个不一定是非负的随机变量 \(Y\)，那么类似的论证可以用来证明 \(Y\) 的绝对值 \(|Y|\) 的以下结果：

    定理 19.2（广义马尔可夫不等式）。令 \(Y\) 为一个具有有限均值的任意随机变量。那么，对于任何正数常数 \(c\) 和 \(r\)，有

    \[ \mathbb{P}[|Y| \geq c] \leq \frac{\mathbb{E}[|Y|^r]}{c^r}. \]

    证明。由于 \(c > 0\) 且 \(r > 0\)，我们有

    \[ |Y|^r \geq |Y|^r I\{|Y| \geq c\} \geq c^r I\{|Y| \geq c\}. \]

    （注意，如果 \(r\) 是负数，最后一个不等式将不成立。）取两边的期望得到

    \[ \mathbb{E} \big[ |Y|^r \big] \geq c^r \mathbb{E} \big[ I\{|Y| \geq c\} \big] = c^r \mathbb{P} \big[ |Y| \geq c \big], \]

    除以 \(c^r\) 即可得到所需结果。 \(\square\)

    示例：硬币投掷

    考虑投掷一枚均匀硬币 \(n\) 次，令 \(X\) 表示观察到的正面次数。观察到超过 \(\frac{3}{4} n\) 次正面的概率是多少？让我们应用马尔可夫不等式来获得 \(\mathbb{P}[X \geq \frac{3}{4} n]\) 的上界。由于 \(X \sim \text{Binomial}(n, \frac{1}{2})\)，我们有 \(\mathbb{E}[X] = \frac{1}{2} n\)，因此

    \[ \mathbb{P} [ X \geq \frac {3}{4} n ] \leq \frac {\mathbb {E} [ X ]}{\frac {3}{4} n} = \frac {2}{3}, \]

    这并不依赖于 \(n\) 。这是一个好的上界吗？ \(\mathbb { P } [ X \geq { \frac { 3 } { 4 } } n ]\) 的准确答案由下式给出

    \[ \mathbb {P} [ X \geq \frac {3}{4} n ] = \sum_ {k = \left\lceil \frac {3}{4} n \right\rceil} ^ {n} \binom {n} {k} \frac {1}{2 ^ {n}}, \]

    对于 \(n = 10\)，该值 \(\approx 5.5 \times 10^{-2}\)；对于 \(n = 100\)，该值 \(\approx 2.8 \times 10^{-7}\) 。正如这些数值所示， \(\mathbb{P}[X \geq \frac{3}{4} n]\) 是 \(n\) 的递减函数，因此马尔可夫不等式在这个例子中没有提供一个很好的上界。在下一节中，我们将看到如何获得一个改进的界限。

    2 切比雪夫不等式

    我们已经看到，直观地说，方差（或者更准确地说是标准差）是“离散度”或偏离均值的程度的一种度量。我们现在可以使这种直觉在定量上变得精确：

    定理 19.3（切比雪夫不等式）。对于一个期望有限 \(\mathbb{E}[X] = \mu\) 的随机变量 \(X\)，有

    \[ \mathbb {P} [ | X - \mu | \geq c ] \leq \frac {\operatorname {V a r} (X)}{c ^ {2}}, \tag {2} \]

    对于任何正数常数 \(c\) 均成立。

    证明。定义 \(Y = (X - \mu)^2\) 并注意 \(\mathbb{E}[Y] = \mathbb{E}[(X - \mu)^2] = \text{Var}(X)\) 。此外，注意我们感兴趣的事件 \(|X - \mu| \geq c\) 与事件 \(Y = (X - \mu)^2 \geq c^2\) 完全相同。因此， \(\mathbb{P}[|X - \mu| \geq c] = \mathbb{P}[Y \geq c^2]\) 。此外， \(Y\) 显然是非负的，所以我们可以应用定理 19.1 中的马尔可夫不等式来得到

    \[ \mathbb{P}[|X - \mu| \geq c] = \mathbb{P}[Y \geq c^2] \leq \frac{\mathbb{E}[Y]}{c^2} = \frac{\text{Var}(X)}{c^2}. \]

    证明完毕。 \(\square\)

    这里有一个使用定理 19.2 中广义马尔可夫不等式的更简单的证明：

    定理 19.3 的另一种证明。定义 \(Y = X - \mu\) 。那么，由于 \(|Y|^2 = |X - \mu|^2 = (X - \mu)^2\)，我们有 \(\mathbb{E}[|Y|^2] = \mathbb{E}[(X - \mu)^2] = \text{Var}(X)\) 。因此，通过将定理 19.2 应用于 \(Y = X - \mu\) 且 \(r = 2\) ，可以得到 (2)。 \(\square\)

    让我们停下来思考一下切比雪夫不等式说明了什么。它告诉我们，任何给定的偏离均值的幅度 \(c\)（无论是高于还是低于均值，请注意绝对值符号）的概率最多为 \(\frac{\text{Var}(X)}{c^2}\) 。正如预期的那样，如果方差很小，这种偏差概率也会很小。切比雪夫不等式的一个直接推论如下：

    推论 19.1。对于任何期望有限 \(\mathbb{E}[X] = \mu\) 且标准差有限 \(\sigma = \sqrt{\text{Var}(X)}\) 的随机变量 \(X\)，有

    \[ \mathbb {P} [ | X - \mu | \geq k \sigma ] \leq \frac {1}{k ^ {2}}, \]

    对于任何常数 \(k > 0\) 均成立。

    证明。将 \(c = k\sigma\) 代入切比雪夫不等式即可。 \(\square\)

    因此，例如，我们看到偏离均值超过（比如）两个标准差的概率最多为 \(\frac{1}{4}\) 。从这个意义上说，标准差是分布“宽度”或“传播范围”的一个很好的实用定义。

    在某些特殊情况下，可以获得关于偏离均值概率的更紧确界。然而，对于仅具有均值和方差的一般随机变量，切比雪夫不等式基本上是唯一的工具。它的强大之处在于它可以应用于任何具有均值和方差的随机变量。

    示例：再谈硬币投掷

    让我们回顾上面考虑过的硬币投掷示例，并应用切比雪夫不等式来获得 \(\mathbb{P} [ X \geq \frac{3}{4} n ]\) 的上界。回想 \(\mathbb{E}[X] = \frac{n}{2}\)，我们得到

    \[ \mathbb {P} [ X \geq \frac {3}{4} n ] = \mathbb {P} [ X - \frac {n}{2} \geq \frac {n}{4} ] \leq \mathbb {P} [ | X - \frac {n}{2} | \geq \frac {n}{4} ] \leq \frac {\operatorname {V a r} (X)}{\left(\frac {n}{4}\right) ^ {2}}. \]

    由于 \(X \sim \text{Binomial}(n, \frac{1}{2})\)，我们有 \(\text{Var}(X) = n \cdot \frac{1}{2}(1 - \frac{1}{2}) = \frac{n}{4}\)，因此我们得到

    \[ \mathbb {P} [ X \geq \frac {3}{4} n ] \leq \frac {\operatorname {V a r} (X)}{\left(\frac {n}{4}\right) ^ {2}} = \frac {4}{n}, \]

    这比马尔可夫不等式给出的常数界限 \(\frac{2}{3}\) 要好得多。

    3 应用

    在本节中，我们将讨论切比雪夫不等式在估计问题中的应用。

    3.1 估计硬币的偏差

    让我们回到估计硬币偏差的那个激励示例。回想一下，我们有一枚未知偏差 \(p\) 的硬币，我们对 \(p\) 的估计是 \(\hat{p} = \frac{1}{n} S_n\)，其中 \(S_n\) 是 \(n\) 次硬币投掷中正面的次数。

    通常，我们会发现将 \(S_n = X_1 + \cdots + X_n\) 写出来很有帮助，其中如果第 \(i\) 次投掷为正面则 \(X_i = 1\)，否则 \(X_i = 0\)，且随机变量 \(X_1, \ldots, X_n\) 是 独立同分布 （Independent and Identically Distributed, i.i.d.）的。那么 \(\mathbb{E}[X_i] = \mathbb{P}[X_i = 1] = p\)，因此根据 期望的线性性质 （Linearity of Expectation），

    \[ \mathbb {E} [ \hat {p} ] = \mathbb {E} \left[ \frac {1}{n} S _ {n} \right] = \frac {1}{n} \sum_ {i = 1} ^ {n} \mathbb {E} \left[ X _ {i} \right] = p. \]

    那么 \(\hat{p}\) 的方差呢？注意，由于 \(X_i\) 是独立的，\(S_n = \sum_{i=1}^n X_i\) 的方差等于方差之和：

    \[ \operatorname {V a r} (\hat {p}) = \operatorname {V a r} (\frac {1}{n} S _ {n}) = \frac {1}{n ^ {2}} \operatorname {V a r} (S _ {n}) = \frac {1}{n ^ {2}} \sum_ {i = 1} ^ {n} \operatorname {V a r} (X _ {i}) = \frac {\sigma^ {2}}{n}, \]

    其中我们将每个 \(X_i\) 的方差记为 \(\sigma^2\) 。

    因此我们看到，\(\hat{p}\) 的方差与 \(n\) 成反比。这一事实确保了，随着我们采集更大的样本量 \(n\)，我们偏离期望值 \(p\) 的概率会越来越小。

    现在让我们使用切比雪夫不等式来计算 \(n\) 需要多大，才能确保我们对真实偏差 \(p\) 的估计达到指定的准确度。正如我们在本讲义开始时讨论的那样，一种自然的衡量方法是我们指定两个参数 \(\varepsilon\) 和 \(\delta\)，它们都在 \((0, 1)\) 范围内。参数 \(\varepsilon\) 控制我们准备在估计中容忍的误差，而 \(\delta\) 控制我们希望对估计具有的置信度。

    应用切比雪夫不等式，我们有

    \[ \mathbb {P} [ | \hat {p} - p | \geq \varepsilon ] \leq \frac {\operatorname {V a r} (\hat {p})}{\varepsilon^ {2}} = \frac {\sigma^ {2}}{n \varepsilon^ {2}}. \]

    为了使右侧小于目标值 \(\delta\)，我们需要设置

    \[ n \geq \frac {\sigma^ {2}}{\varepsilon^ {2} \delta}. \tag {3} \]

    现在回想一下， \(\sigma^2 = \text{Var}(X_i)\) 是单个样本 \(X_i\) 的方差。由于 \(X_i\) 是一个具有 \(\mathbb{P}[X_i = 1] = p\) 的指示随机变量，我们有 \(\sigma^2 = p(1-p)\)，并且 (3) 中的不等式变为 \(n \geq \frac{p(1-p)}{\varepsilon^2 \delta}\) 。由于 \(p(1-p)\) 在 \(p = \frac{1}{2}\) 时达到最大值，我们可以得出结论，选择 \(n\) 满足以下条件就足够了：

    \[ n \geq \max _ {p} \frac {p (1 - p)}{\varepsilon^ {2} \delta} = \frac {1}{4 \varepsilon^ {2} \delta}, \tag {4} \]

    正如我们之前所声称的那样。

    例如，代入 \(\varepsilon = 0.1\) 和 \(\delta = 0.05\)，我们看到样本量 \(n = 500\) 足以获得一个估计值 \(\hat{p}\)，其误差在 0.1 以内的概率至少为 95% 。

    作为一个具体的例子，考虑通过随机抽样来估计美国人口中民主党人的比例 \(p\) 。我们可以将其建模为上面的硬币偏差估计问题，其中每次硬币投掷对应于我们从整个人口中随机选择的一个人，并且这些投掷是独立的。我们上面的计算表明，要获得一个误差在 0.01 以内且概率至少为 95% 的估计值 \(\hat{p}\)，采样 \(n = 50,000\) 人就足够了。特别要注意的是，样本量与人口总数无关！这就是为什么民意调查可以在仅采样相当少的人的情况下，准确估计数亿人口感兴趣的量。

    3.2 估计一般期望

    如果我们想估计一些比硬币偏差稍微复杂一点的东西呢？例如，假设我们想估计美国人的平均财富。我们可以将其建模为估计未知概率分布的期望值的问题。然后我们可以使用与以前完全相同的方案，不同之处在于现在我们从未知分布中独立地对随机变量 \(X_1, X_2, \ldots, X_n\) 进行采样。显然 \(\mathbb{E}[X_i] = \mu\)，即我们要尝试估计的期望值。我们对 \(\mu\) 的估计将是 \(\hat{\mu} = \frac{1}{n} \sum_{i=1}^n X_i\)，对应一个适当选择的样本量 \(n\) 。

    遵循与之前相同的计算，我们有 \(\mathbb{E}[\hat{\mu}] = \mu\) 且 \(\text{Var}(\hat{\mu}) = \frac{\sigma^2}{n}\)，其中 \(\sigma^2 = \text{Var}(X_i)\) 是 \(X_i\) 的方差。（回想一下，我们对 \(X_i\) 唯一使用的性质是它们是独立的且具有相同的分布——实际上具有相同的期望和方差就足够了：为什么？）然而，这一次，由于我们没有关于均值 \(\mu\) 的先验界限，让 \(\varepsilon\) 成为 相对误差 （Relative Error）更有意义，即我们希望找到一个估计值 \(\hat{\mu}\)，其加性误差在 \(\varepsilon \mu\) 之内：

    \[ \mathbb {P} [ | \hat {\mu} - \mu | \geq \varepsilon \mu ] \leq \delta . \]

    使用 (3)，但用 \(\varepsilon \mu\) 代替 \(\varepsilon\)，样本量 \(n\) 满足以下条件就足够了：

    \[ n \geq \frac {\sigma^ {2}}{\mu^ {2}} \times \frac {1}{\varepsilon^ {2} \delta}. \tag {5} \]

    这里 \(\varepsilon\) 和 \(1 - \delta\) 分别是所需的相对误差和 置信水平 （Confidence Level）。现在当然我们不知道 (5) 中出现的另外两个量 \(\mu\) 和 \(\sigma^2\) 。在实践中，我们会使用 \(\mu\) 的下界和 \(\sigma^2\) 的上界（就像我们在投硬币问题中使用 \(p(1 - p)\) 的上界一样）。将这些界限代入 (5) 将确保我们的样本量足够大。

    例如，在平均财富问题中，我们大概可以安全地假设 \(\mu\) 至少为（比如）20,000 美元（可能更多）。然而，像比尔·盖茨这样的富豪的存在意味着我们需要为方差 \(\sigma^2\) 取一个非常高的值。事实上，如果在 3.25 亿人口中至少有一个拥有 500 亿美元财富的个人，那么假设较小的 \(\mu\) 值意味着方差必须至少约为 \(\frac{(50 \times 10^9)^2}{325 \times 10^6} \approx 7.7 \times 10^{12}\) 。对于简单的均匀抽样，确实没有办法避开这个问题：财富分配不均意味着方差本质上非常大，我们需要大量的样本才有可能找到非常富有的人。但如果我们不把这些人包括在我们的样本中，那么我们的估计值就会低得多。

    4 The Law of Large Numbers

    The estimation method we used in the previous sections is based on a principle that we accept as part of everyday life: namely, the Law of Large Numbers (LLN). This asserts that, if we observe some random variable many times, and take the average of the observations, then this average will converge to a single value, which is of course the expectation of the random variable. In other words, averaging tends to smooth out any large fluctuations, and the more averaging we do the better the smoothing.

    Theorem 19.4 (Law of Large Numbers). Let X1, X2,..., be a sequence of i.i.d. (independent and identically distributed) random variables with common finite expectation \(\mathbb { E } [ X _ { i } ] = \mu\) for all i. Then, their partial sums \(S _ { n } = X _ { 1 } + X _ { 2 } + \cdots + X _ { n }\) satisfy

    \[ \mathbb {P} \left[\left| \frac {1}{n} S _ {n} - \mu \right| \geq \varepsilon \right]\rightarrow 0 \quad a s n \rightarrow \infty , \]

    for every \(\varepsilon > 0\) , however small.

    Proof. Let \(\operatorname { V a r } ( X _ { i } ) = \sigma ^ { 2 }\) be the common variance of the r.v.’s; we assume that \(\sigma ^ { 2 }\) is finite.4 With this (relatively mild) assumption, the LLN is an immediate consequence of Theorem 19.3. Since \(X _ { 1 } , X _ { 2 } , \dots\) are i.i.d. random variables with \(\mathbb { E } [ X _ { i } ] = \mu\) and \(\operatorname { V a r } ( X _ { i } ) = \sigma ^ { 2 }\) , we have \(\mathbb { E } \big [ \frac { 1 } { n } S _ { n } \big ] = \mu\) and \(\begin{array} { r } { \operatorname { V a r } ( \frac { 1 } { n } S _ { n } ) = \frac { \sigma ^ { 2 } } { n } } \end{array}\) , so by Chebyshev’s inequality we have

    \[ \mathbb {P} \left[\left| \frac {1}{n} S _ {n} - \mu \right| \geq \varepsilon \right] \leq \frac {\operatorname {V a r} \left(\frac {1}{n} S _ {n}\right)}{\varepsilon^ {2}} = \frac {\sigma^ {2}}{n \varepsilon^ {2}} \rightarrow 0 \quad \text {a s} n \rightarrow \infty . \]

    Notice that the LLN says that the probability of any deviation ε from the mean, however small, tends to zero as the number of observations \(n\) in our average tends to infinity. Thus, by taking \(n\) large enough, we can make the probability of any given deviation as small as we like.
